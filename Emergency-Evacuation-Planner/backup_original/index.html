📚 Discrete Mathematics Used

🕸️ Graph Theory

Building locations are represented as vertices and corridors are represented as edges.

🚶 Paths & BFS

Breadth-First Search is used to find an evacuation path from a location to the exit.

🔗 Relations

Connections between locations form a binary relation represented using an adjacency matrix.

🔍 Warshall's Algorithm

Transitive closure is used to determine whether one location can reach another.

🧠 Logic

A route is considered safe when both a usable route and an available exit exist: P ∧ Q.

🔢 Functions

Emergency resources are mapped to locations using a location-to-resource function.

📐 Mathematical Representation

The building is represented as an undirected graph G = (V, E).

Vertices (V)

V = {A, B, C, D, E, F, G, EXIT}

Edges (E)

E = { (A,B), (B,C), (A,D), (B,E), (C,F), (D,E), (E,F), (E,G), (G,EXIT) }

Graph Representation

Each location is a vertex and each corridor between two locations is an edge.
